A.D.A.C.H.I. é uma experiência interativa de enigmas, investigação e exploração criada para desafiar a percepção de quem decide seguir adiante.
O projeto começa como uma sequência aparentemente simples de desafios, mas, conforme o participante avança, novas camadas são reveladas. Códigos, mensagens, referências históricas, matemática, criptografia e elementos ocultos fazem parte do caminho.
Nem tudo foi colocado para ser encontrado.
E nem tudo que for encontrado terá uma explicação imediata.
A experiência foi desenvolvida para que o próprio site faça parte do enigma. A interface, os arquivos, as mensagens e até determinadas limitações do sistema podem esconder informações importantes para a progressão.
Os primeiros desafios funcionam diretamente no navegador. Conforme o participante avança, a estrutura da experiência se torna mais complexa, levando a etapas protegidas por servidor e mecanismos de acesso individuais.
Você não está apenas resolvendo enigmas.
Está descobrindo até onde consegue chegar.

A.D.A.C.H.I.
