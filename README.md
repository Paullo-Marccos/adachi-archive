A.D.A.C.H.I é uma experiência interativa de enigmas, investigação e exploração desenvolvida para desafiar a percepção de quem decide seguir adiante.

O que começa como uma sequência aparentemente simples de desafios revela, a cada avanço, novas camadas de complexidade. Códigos, referências históricas, matemática, criptografia e elementos ocultos compõem o caminho.

---

👁️ Sobre o Projeto

- O Site como Enigma: A interface, os arquivos, as mensagens e as próprias limitações do sistema podem conter informações cruciais para a progressão.
- Evolução da Estrutura: Os desafios iniciais operam diretamente no navegador. Conforme o acesso se aprofunda, a estrutura evolui para etapas protegidas por servidor e mecanismos de acesso individuais.
- Exploração Ativa: Nem tudo foi colocado para ser encontrado. E nem tudo o que for encontrado terá uma explicação imediata.

> Você não está apenas resolvendo enigmas. Está descobrindo até onde consegue chegar.
